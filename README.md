# ⚡ ZEUS 1-Click Cloudflare Auto-Deployer (Zero-Secret GitHub Actions)

سامانه استقرار خودکار، جهش چندریختی و شخصی‌سازی پنل زئوس روی شبکه جهانی کلودفلر — **بدون نیاز به هیچ‌گونه سکرت یا کانفیگ دستی در مخزن گیت‌هاب**.

---

## 🌟 ویژگی‌های کلیدی

1. **استقرار خودکار روی GitHub Pages (بدون هیچ سکرتی)**:
   - به محض Fork یا Push کردن این مخزن، گیت‌هاب اکشن با ورک‌فلو `deploy-pages.yml` وب‌اپلیکیشن را روی دامنه رایگان `https://<username>.github.io/<repo-name>/` بالا می‌آورد.
   - هیچ نیازی به اضافه کردن `Secret` یا متغیر محیطی در تنظیمات ریپازیتوری نیست.

2. **فقط با یک توکن کلودفلر (1-Click Deployment)**:
   - کاربر نهایی فقط کلید API Token کلودفلر را وارد می‌کند.
   - بقیه مراحل (تولید نام رندوم، مسیر ادمین اختصاصی، UUID نسخه ۴، مبهم‌سازی سورس، ساخت دیتابیس D1 و پابلیش ورکر) ۱۰۰٪ خودکار انجام می‌شود.

3. **اجرای مستقیم از تب GitHub Actions (Manual Runner)**:
   - بدون نیاز به سرور اختصاصی؛ می‌توانید در تب **Actions** گزینه **Deploy Zeus Worker to Cloudflare** را انتخاب کنید و دکمه **Run workflow** را بزنید تا کلودفلر ورکر ساخته شود.

---

## 🚀 روش راه‌اندازی و استفاده

### گام ۱: ساخت ریپازیتوری در گیت‌هاب
1. این ریپازیتوری را در اکانت خود **Fork** یا **Push** کنید.
2. در تنظیمات مخزن: **Settings -> Pages -> Build and deployment**:
   - بخش **Source** را روی **GitHub Actions** قرار دهید.
3. گیت‌هاب اکشن به‌صورت خودکار وب‌اپلیکیشن را منتشر می‌کند.

### گام ۲: استفاده از وب‌اپلیکیشن
1. آدرس سایت گیت‌هاب پیجز خود را باز کنید (`https://<username>.github.io/<repo-name>/`).
2. کلید **Cloudflare API Token** خود را در کادر وارد کنید.
3. دکمه **«⚡ استقرار خودکار و آنلاین پنل زئوس»** را بزنید.
4. پس از چند ثانیه، لینک مستقیم پنل ادمین و لینک سابسکریپشن را تحویل بگیرید!

---

## 🔑 دسترسی‌های لازم برای توکن کلودفلر (Cloudflare Token Permissions)
برای ساخت توکن در داشبورد کلودفلر (**My Profile -> API Tokens -> Create Token -> Custom Token**)، دسترسی‌های زیر کافی است:
- `Account` -> `Workers Scripts` -> `Edit`
- `Account` -> `D1` -> `Edit`
- `User` -> `Memberships` -> `Read`

```
├── .github/
│   └── workflows/
│       ├── deploy-pages.yml       # استقرار خودکار وب‌اپلیکیشن روی GitHub Pages (بدون سکرت)
│       └── deploy-zeus-worker.yml # رانر دستی جهت استقرار مستقیم در کلودفلر
├── index.html                     # وب‌اپلیکیشن اصلی تعاملی
├── deploy.py                      # اسکریپت پایتون استقرار و مبهم‌سازی خودکار
└── README.md                      # مستندات کامل
```
